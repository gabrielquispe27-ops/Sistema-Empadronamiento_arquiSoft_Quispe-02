# Identificar Historias de Usuario

Descripción de las principales necesidades desde la perspectiva de los actores.

| ID | Historia de usuario |
|---|---|
| HU01 | Como brigadista, quiero registrar los datos demográficos y daños materiales de los damnificados, para empadronarlos rápidamente en el campo de emergencia. |
| HU02 | Como brigadista, quiero que el sistema valide la información que ingreso (como formato y longitud del DNI), para asegurar la integridad de los datos en el padrón. |
| HU03 | Como coordinador de Defensa Civil, quiero visualizar un dashboard con la información consolidada del padrón, para tomar decisiones logísticas de ayuda humanitaria basadas en datos reales. |
| HU04 | Como coordinador de Defensa Civil, quiero generar reportes de personas empadronadas por zonas, para identificar el avance de la cobertura de la ayuda. |
